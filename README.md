# My Shop - Flask Ecommerce Web Application

A full-stack ecommerce web app built using:

- Python (Flask)
- MySQL
- HTML
- CSS

## Features
- User Registration & Login
- Add to Cart
- Quantity Selection
- Cart Sidebar
- Place Order
- Stock Management
- Order History

## Tech Stack
Backend: Flask + SQLAlchemy  
Frontend: HTML + CSS  
Database: MySQL
